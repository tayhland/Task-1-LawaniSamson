# Customer Orders Data Cleaning
# Objective
To inspect and clean a customer orders dataset by identifying missing values, duplicate records and formatting inconsistencies.
## Dataset
- Rows: 1,201
- Columns: 14
- Type: Customer Orders
## Cleaning process
- Checked for missing values
- Removed duplicate rows
- Standardised column names
- Verified data types
- Inconsistent formatting was confirmed
# Result
No duplicate records were found, column names were formatted properly, columns with missing values were replaced with values
